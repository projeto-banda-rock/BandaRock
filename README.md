## Sobre o Projeto
O RockLegends é uma solução web desenvolvida para reunir a história, a discografia e os integrantes das maiores bandas de rock de todos os tempos (como Queen, Pink Floyd, AC/DC, Metallica, entre outras). Desenvolvido para proporcionar uma imersão visual marcante, o sistema oferece uma interface temática com estética única para cada banda, unindo interatividade, animações e organização de dados. Elaborado no curso de Desenvolvimento de Sistemas do SENAI Sorocaba - Gaspar Ricardo Junior, ministrado pelo Prof. [Vedilson Prado](http://github.com/vedilsonprado).


#### O Diferencial: Arquitetura e Imersão Visual

Diferente de um site institucional, a plataforma combina interatividade com uma estrutura preparada para integração de dados:
- **Interface Dinâmica & Temática (HTML5/CSS3):** Layouts personalizados com paletas de cores fiéis a cada banda, molduras customizadas, fundos adaptáveis e suporte a animações visuais (como chuva de vinis para Pink Floyd).
- **Componentes Interativos (JavaScript):** Gerenciamento dinâmico de múltiplos modais modulares (exibindo integrantes, discografia e álbuns mais vendidos em posições específicas da tela) e controle de eventos de tela.
  
---  

## Tecnologias Utilizadas

### Frontend
- **HTML5:** Estrutura semântica para a renderização dos cards principais, modais informativos e seções de rodapé.
- **CSS3:** Estilização, efeitos de transparência, bordas temáticas, responsividade e animações.
- **JavaScript (ES6+):** Controle de abertura/fechamento dos modais, animações interativas.

---

## Estrutura do sistema

### Interface & Telas
- **Card Central de Destaque:** Exibição da banda selecionada com história principal, tipografia personalizada e fundo tematizado.
- **Modal de Integrantes:** Janela interativa exibindo a formação clássica dos músicos e seus respectivos instrumentos.
- **Modal de Discografia/Álbuns:** Janela informativa detalhando o álbum mais vendido, grandes sucessos e faixas marcantes.
- **Rodapé com Copyright:** Seção fixa para identificação do projeto e dados de direitos autorais.
  
---

## Como executar o projeto

### 1. Frontend
- Navegue até a pasta do BandaRock. 
- Abra o arquivo index.html de qualquer uma das bandas no seu navegador.
